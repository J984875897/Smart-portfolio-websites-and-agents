## 从研究总览开始

首页显示数据版本、候选资格、目标持仓 K 和风险预览，并给出一个“现在建议”。总览只读取状态；打开首页不会下载数据、保存版本或自动计算。

| 入口 | 本页要做什么 | 完成后去哪 |
| --- | --- | --- |
| 01 准备数据 | 打开已有版本，或上传 CSV／XLSX、映射字段、检查并保存 | 02 核对资格 |
| 02 核对资格 | 按缺口选择日线月度、港币收益、共同窗口、历史资格工具 | 03 筛选候选 |
| 03 筛选候选 | 选市场、产品分类、个股开关与 K，查验候选 N 和排除原因 | 数量通过后进入 04 |
| 04 收益与风险 | 核对共用研究输入、选择权重、计算并导出风险诊断 | 查看结果，返回总览 |

工具不会自动串接成一份合格研究资料。真实日线仍需月度准备和完整证据，不能因为某个工具通过就把产品数当作 N。

熟悉系统时，展开「数据工具与证据」选择市场数据、收益与窗口、历史资格或利率因子；「快速跳转至任意工具」可直接到达全部旧工具。每页的「相关工具与下一步」提供回跳，主流程可随时返回「研究总览」。手机上若侧栏挡住内容，收起侧栏后操作。

状态含义：**待输入**表示尚无结果；**待核对**表示已有资料但还需确认；**已阻止**表示本步条件不足；**可继续**仅表示当前具体数量或计算条件通过。人工声明、partial、tls_error 和未认证历史池均不能据此被视为认证成功。

普通设置会保留在本次会话。候选证据、自定义权重和各核对工具的上传资料会保留本次副本；跨页返回时可能显示“本次研究已保留”，可以重新上传替换或点击“清除已保留文件”。保留副本只用于同一来源上下文；更换来源／版本仍要求重新上传候选证据，候选身份变化会重置权重上传。刷新或关闭会话不等于保存研究。

## 先体验收益与风险预览

1. 在研究总览点击「试用人工演示」，进入「03 筛选候选」，数据来源已选「SYNTH 相关性与风险演示」。其他设置保留默认，点击「查验数据并筛选」。应显示 K30、N100、数量条件通过。
2. 点击「前往收益与风险」，保留「合格候选等权预览」，点击「计算收益与风险」。这是100项候选等权风险诊断，不是选出了30项。研究输入在上方折叠区；修改后需重新筛选。
3. 「收益估计」查看每项历史／估计收益与两种波动；「相关性」查看原始月收益热图和产品对。默认前20项，可选择2–30项查看，不改变候选数量或权重。
4. 「风险与分散化」对照经验协方差与收缩模型，查看波动、DR、有效持仓数及风险贡献。图中保留负贡献；完整表可横向滚动。有效持仓数只衡量权重集中，不是独立风险来源数。
5. 「方法与导出」下载完整收益、协方差、相关矩阵、两种风险贡献和证据，共9份文件。CSV使用小数，0.01表示1%；JSON不可用值为null。

上传自己的权重：选择「上传自定义多头权重 CSV」，下载本次模板后填写。只允许 `asset_id,weight` 两列，每个合格ID出现一次；零持仓写0，非负小数总和必须为1。系统不会归一化，不会自动补零。正权重数量可以暂时不等于K，但始终属于研究预览。

人工风险案例中，`SYNTH_SCREEN_001`与`002`完全同向，两项各50%、其余0时经验DR应为1；`003`与`001`反向，前者20%、后者80%、其余0时有负风险贡献。`000`收益恒定，其Pearson相关性（包括自身）不可用；模型波动可能大于经验零波动。例子只验证计算与显示，不是市场投资表现。

原来的「SYNTH 100项边界演示」收益全恒定，全部相关性及零波动DR应不可用。真实日线输入仍N0，不能从这里跳过数据准备或历史资格要求。

修改原始数据、筛选条件或权重会撤下旧结果和下载，需重算；表格搜索、相关性子集／排序及风险贡献口径只改变展示。来源或筛选身份改变后会重置权重上传，避免旧权重沿用到新候选池。窄屏相关热图与完整表可在容器中横向滚动。

新版界面验收与截图见 [UI 重设计](../outputs/acceptance/UI_REDESIGN/README.md)，原风险接入记录见 [S06-C](../outputs/acceptance/S06C/README.md)。公式与手算可继续查验 [S06-A](../outputs/acceptance/S06A/README.md)、[S06-B](../outputs/acceptance/S06B/README.md)。开发复算命令：`.venv/bin/python scripts/verify_estimation.py` 和 `.venv/bin/python scripts/verify_diversification.py`。

## 先体验候选筛选

1. 左侧选择「03 筛选候选」，保留「SYNTH 100项边界演示」及默认窗口／决策时间，K保持30。
2. 点击「查验数据并筛选」，应看到N100、K/N30%、缺口0和数量条件通过。
3. 在「手动排除」搜索并选中SYNTH_SCREEN_099；旧结果和下载撤下。重新点击查验，N变99、缺口1，提示“候选产品池过小”。
4. 产品表前三列显示状态、产品名称、原因。搜索／展示状态／翻页只改变表格，N不变；CSV导出始终包含完整查验，合格矩阵只含通过列。

使用自己的资料：先去「01 准备数据」保存或打开版本，再返回选择「当前已打开导入版本」。本页上传月末汇率（HKD可不提供）、逐月时间、结构资料CSV／XLSX并选择工作表，格式与空白模板在折叠说明内。结构与时间须有来源，ETF同样需要结构声明。已有真实日线尚未桥接到共同月度窗口，N0属于预期阻止；不能仅修改频率标签。

默认不允许直接个股，但保留股票ETF／基金。改变来源、证据、范围或参数后需重算；换来源／版本须重新上传证据并确认复权口径。本页不联网、不自动扩充候选、不选择实际成员。窄屏若侧栏挡住内容，点击左上角双箭头收起。

## 第一次：用三分钟看懂一个结果

1. 在侧栏「快速跳转至任意工具」选择「日线港币查验」。保留人工案例、完整报价、SPY，月份均为 `2025-01`。
2. 勾选复权价格确认、每美元兑港币确认，点击「查验并计算港币收益」。港币收益应约为 **11.4103%**。这是人工案例。
3. 汇率改成「缺期末月」，重新计算，应显示阻止。修改参数时旧结果会撤下，需要重新点击计算。
4. 切到「历史资格与来源」，选择「SYNTH 时间案例」。默认通过 **1** 月；决策时点改为 `2025-02-01T23:59:59.999999Z`，按 Enter，通过变为 **0** 月。该页会自动重算。

收益公式为 `(1 + 原币收益) × (1 + 汇率收益) − 1`。能计算收益与能证明某个版本在过去已取得，是两件分别查验的事。

## 自己的数据走哪条路

| 想做什么 | 页面与顺序 | 得到什么 |
| --- | --- | --- |
| 导入自己的 CSV／XLSX | 数据导入 → 字段映射／产品类型 → 质量检查 → 仅保存可接受行 | 可重读的本地数据版本和质量报告 |
| 导入月度收益并换成 HKD | 数据导入 → 港币收益查验 → 共同窗口查验 | 汇率对照、固定窗口及逐项排除原因；共同窗口仍需另给声明时间证据 |
| 下载行情 | 下载与缓存 → 生成计划 → 核对 → 开始下载 | 独立快照、逐项状态；成功价格可送入数据导入核对，但不会自动保存 |
| 检查日线并看原币收益 | 日线月度查验 | 交易日历代理、缺日诊断、原币月收益 |
| 日线价格换成 HKD | 日线港币查验 | 原币／FX／交叉项／HKD 对照；美元产品需另选 FX 来源 |
| 核对日线结果的本地取得时间 | 日线港币查验计算后 → 历史资格查验 | 同一浏览器会话内交接的时间证据及阻止原因 |
| 下载因子／官方汇率 | 因子与官方汇率 → 计划／下载，或打开缓存 | 四套 French 因子；HKMA 当前不可用，保留失败记录 |
| 检查港币现金代理 | 港币利率查验 | 人工或文件输入的 HIBOR 单利月收益代理；尚无真实自动报价下载 |

美元日线需要完整前月和目标月。以一月为例，下载区间为 `2024-12-01` 至 `2025-02-01`，结束日不包含。范围更长不保证数据更完整，应看逐项状态。缓存版本不会因“更新”被覆盖。

## 看到这些状态时怎么办

| 状态 | 含义与下一步 |
| --- | --- |
| success | 来源字段检查通过；还需通过收益、日期和时间查验 |
| partial／source_not_success | 来源不完整；查看诊断，保留原始版本，可另行下载或导入有来源记录的数据 |
| unavailable／tls_error | 来源请求失败；HKMA 本轮仍属此类，可使用明确标记的其他 FX 来源或授权文件 |
| 缺少下载完成时间 | 旧缓存没有 `completed_utc`；仍可读取，但不能回填时间来获得历史资格 |
| 本地取得版本晚于决策时点 | 今天的下载不能证明过去已持有该版本；使用真实研究时点，不倒填 |
| 仅人工声明 | 输入者提供的时间说明，不等于已验证快照证据 |

刷新或重新打开会话可能丢失尚未保存的跨页结果。导出文件和已保存版本用于留存；换参数后重新计算。C3 只证明本地版本时间，不证明源站发布时间、退市覆盖或历史可投资名单完整。
