# S02 文件导入与查验界面

依据已批准的分步开发计划 S02，本轮仅交付文件导入、产品分类映射、来源追踪及质量报告。S00／S01 的 45 项基线检查通过；无 Git 仓库，在原工作区修改。

## 流程与口径

本地 CSV／XLSX 或明确标记的合成示例 → 查看原始行 → 映射字段及默认值 → 检查并预览 → 明确接受可入库行 → 保存新 DataBundle 版本。导入不会联网。文件单位、频率和收益／价格口径由用户指定；百分数 2 转换为小数 0.02，价格不作百分数转换。原币仍为原币，HKD 换算在 S03。

工具类型（如 stock、ETF、mutual_fund、bond、gold_trust）与经济资产类别（如 equity、government_bond、credit_bond、commodity、mixed）分开。逐行字段覆盖明确的默认值，未知值不能悄悄回退成股票。用户可修改分类或显式映射来源别名，修改保留来源、原值、新值和时间。

稳定资产标识优先；否则使用明确交易所、代码、币种和份额类别确定身份。不根据相似名称合并，不自动把不同币种柜台合并。标识歧义须人工映射。重复产品／相同观察保持一条，新增来源行保留追踪。冲突数据进入阻止状态，不覆盖已有记录。

日期及非有限数值错误、非正价格、收益小于 -100%、必要分类或数值缺失阻止该行。合法的极端收益保留原值并要求核对。本步以绝对单期收益达到 50% 为提示阈值，只是导入诊断，不是投资限制。缺失值不填零。月频同月冲突须检查，完整估值及收益生成留到 S03。

DataBundle 保存 assets、observations、已提供本币收益视图、来源、别名、分类修改记录及质量报告；fx／factors 暂为空。版本目录拒绝覆盖，表文件和原输入校验值可复查。S04 再交付生产级下载和缓存更新。

## 界面选择

采用计划中的轻量本地 Streamlit 页，便于金融核心保持独立；原生控件支持字段映射、Excel sheet 选择、逐行修正和表格下载。页面只有数据导入工作区，没有尚未可用的优化或收益预测按钮。

视觉方向为研究数据工作台：白色 #FFFFFF、浅蓝灰 #EEF3F8、深海蓝 #18334C、湖蓝 #176B87、检查橙 #B66B16、错误红 #A53838。中文正文采用本机 PingFang／系统字体，数据和标识用 SFMono／等宽字体。页面按真实流程排列“文件／映射／预览／已保存数据”，最醒目的内容是每个问题的文件名、行号和处理状态。使用原生表格，避免视觉装饰影响核对。

## 本轮工作与验收

1. 核心及 CSV／XLSX 回归检查：先 RED，后最小实现，再 GREEN。
2. 核心独立审查，解决会影响来源追踪、去重和数值正确性的发现。
3. 预览界面及交互检查：检查配置改变使旧预览失效，重复导入不虚增，核对项需要明确勾选。
4. 真实启动本地服务并检查 HTTP 健康；离线重新读取保存版本，生成验收 CSV 和记录。

验收必须包括 10 个产品再上传 2 个仍为 10、百分数转换、股票 ETF 分类保留、缺分类阻止、NaN 保留、冲突拒绝、CSV／Excel 同结果及来源追踪。测试通过不代表正式合格候选数 N，通过 S03／S05 前不作数量比例或投资组合结论。

## 自查

已确认需求与新增诊断假设分开；S02 不产生 HKD 收益、不验证 60 月投资资格、不自动下载、不选择真实持仓。无待填占位；保存、导入和查验均在用户授权的本地范围内。
