# S04-A：美港小样本手动下载与缓存

用户已批准分步计划并要求“进行下一步”。本轮落实 S04 的第一个可查验单元，不重复征求既有授权。

## 方案与范围

采用已在 S01 验证的 Yahoo chart 原始响应路径，先交付下载、原始快照、离线读取及导入交接。一次接完 Yahoo/French/HKMA 会混合不同频率、分页和认证规则；只做缓存底座则用户无法在界面验证，所以两者均不采用。

范围固定为 AAPL、0700.HK、SPY、2800.HK、AGG、GLD、HKD=X 七个识别样本，可多选。不是全市场扫描，不足以验证正式候选数量。French、HKMA、任意代码发现以及日线到 S03 月度输入的聚合分别留到后续子步骤。

## 下载及失败语义

日期严格 YYYY-MM-DD，起日包含、止日不含，start < end；每项一次公开 chart 请求，interval=1d，保留分红、拆股、capital gains。HTTP 请求不自动重试、不接收 key、不登录。请求数等于所选项数；展示是本适配器请求数，不是其他库的隐含调用数。超时默认 15 秒，范围 1–30 秒。用既有 yfinance 安装带来的 curl_cffi 客户端；先 import yfinance 完成本机动态库初始化，但不调用其 history 或内部单例，不修改全局会话。

提取复用 S01 的 parse_yahoo_chart 和 audit_price 为正式 providers/yahoo.py，并让原脚本导入它们；不得另写价格、公司行动或质量公式。验证返回代码、币种、工具类型，保留缺失价格 NaN。每项状态 success / partial / unavailable / cancelled；success 只表示来源字段检查通过，不代表完整交易日历、历史可得时间或 S05 候选合格。

429 为 rate_limited，不重试；非 200 为 http_error；超时、断网、格式变化及身份不符以稳定原因码记录，不记录异常文本、认证头、cookie、crumb 或密钥。每项独立，部分成功明确展示。支持注入 fetch 和取消判定供离线验证；取消在项开始前及请求返回后检查，已完成项保留，不发布取消项。

## 原始证据与版本

每次请求计划生成唯一 run_id，完成后把临时目录原子重命名为 downloads/runs/<run_id>。snapshot_manifest.json 记录范围、UTC 下载时间、provider/version、逐项状态和文件 SHA-256/字节数。原始 chart 响应按原字节保存；派生日线和导入 CSV 都在清单校验内。失败尝试是更新记录，只有 success 项是可用缓存版本；partial 数据仅作检查与导出，不覆盖可用版本。没有隐式“全量最新”指针；用户明确选择某个旧版本，避免混称不同下载时间。旧目录始终不修改。

读取校验清单和所有文件哈希，拒绝路径越界、符号链接越界、损坏或非本格式 run_id。使用缓存不触发任何网络。下载失败或本地写入失败不会改变用户当前已打开的缓存和 S02 bundle。临时未完成目录不显示为版本。update_log.csv 为清单派生导出，逐项保留 run_id、symbol、start/end、状态、原因及缓存状态。

## 界面与导入交接

新增侧栏“下载与缓存”，保留全部已有页面。默认不联网，依次选择样本和日期 → 生成下载计划 → 显示逐项身份、币种、原币日线口径、请求数及限制 → 明确点击“开始下载”或“取消下载计划”。参数变化使旧计划失效。取消是开始前取消，界面明说运行中单次请求最多按配置等待，不承诺按钮可中止在途 HTTP。

更新结果与已打开缓存分开，失败后仍显示旧缓存及其日期。缓存选择、打开、导出、导航和参数变化均不得请求网络。成功产品缓存可“送至导入查验”：使用现有 S02 set_source、read_file、preview_import 流程；带齐同名身份字段，value 为 adj_close，kind=adjusted_price，供应商含 run_id 与原 JSON SHA-256。清空旧上传识别标记，避免旧上传文件覆盖交接来源；不自动 commit 或保存 bundle。S02 来源旁提供清除旧上传提示/逻辑，交接必须在实际存在旧上传时也有效。HKD=X 仅作为非官方 HKD per USD 日线导出，不作为现金资产导入。原始 JSON 到导入 CSV 的哈希关联保留在快照清单和来源名称。

使用原生 Streamlit 控件，不增加全局字体覆盖。宽窄屏查验无重叠；查看所有内容不要求用户阅读实现细节。

## 验证

离线固定响应验证下载、429、超时、坏格式、身份不符、缺价格、取消、历史修订、损坏、路径逃逸、旧版本不变及无网络读取。AppTest 验证默认零请求、计划失效/取消、逐项结果、失败保留旧缓存、离线读取、导入来源及旧上传交接。最后真实小样本 SPY、2800.HK、HKD=X，2025-01-01 至 2025-02-01；在线成功及模拟成功分别记录。全套回归、真实浏览器宽窄屏、独立审查后再声明 S04-A 通过。
