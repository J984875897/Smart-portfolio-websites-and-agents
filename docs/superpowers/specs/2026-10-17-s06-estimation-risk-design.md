## 方案比较

推荐先计算核心、后风险指标、再页面：能先检查公式和数据边界，各步可独立验收。

另一方案是计算与页面同时实现，可更早交互，但公式、状态与界面错误容易混在一起。仅做样本协方差则更简单，却不能完成原计划的收缩对照要求，尤其在 60 月、100 资产时。

## S06-A 输入与边界

底层函数接受 HKD 小数月收益矩阵、以稳定资产 ID 为索引的经济资产类别、明确训练起止月份。只在指定训练窗口内计算；窗口外数据不得影响均值、类别均值、协方差、数据指纹或数值诊断。另行记录实际取用的窗口和样本数，不把输入中的未来记录当作训练样本。

训练窗口须连续、月末日期唯一，每个资产具有相同月份；至少两个训练月。校验资产 ID 唯一、非空，类别绑定完整，收益为有限实数且不小于 -1；拒绝布尔值、非数值、重复月、缺月、缺值和无资产输入，不补零、不逐对删除。矩阵按资产 ID 排序，类别按 ID 对齐，不依赖输入行列位置。小样本只用于数学核对，不获得正式候选资格。

正式连接层接受 S05 的 CandidateInput 与筛选参数，重新运行 screen_candidates；使用其合格矩阵和类别，绑定输入及筛选指纹。正式入口要求数量条件通过及完整 60 月；不得仅相信外部上传的资格布尔列。S06-A 的此连接层通过离线集成验证，不修改界面。真实样本资格不足时仍阻止，不绕过既有时间证据或产品结构检查。当前研究模式和历史候选认证不足状态原样保留。

## S06-A 数值口径

- 每项历史月算术均值为训练月收益平均值；类别均值为该窗口内同类合格产品的个体均值的等权平均，包含自身。
- 主估计为 `mu_month = 0.5 * individual_mean + 0.5 * class_mean`。保留两个组成项，单成员类别标记收缩没有额外信息。类别缺失直接阻止，不改成零收益或未知类。
- 样本月协方差使用 `ddof=1`，保留为解释及对照。
- 主协方差使用 scikit-learn LedoitWolf，先中心化（`assume_centered=False`），其经验协方差采用分母 T，收缩目标是平均方差乘单位矩阵。记录系数、目标、分母及估计器版本；不把它描述为对 ddof=1 样本矩阵直接收缩。
- 年化采用 `mu_ann=12*mu_month`、`Sigma_ann=12*Sigma_month`、`sigma_ann=sqrt(diag(Sigma_ann))`。这是算术估计及月度缩放，披露依赖序列相关性等假设，不称 CAGR，也不保证未来收益。
- 检查有限值、对称性、资产顺序和半正定。特征值数值容差为 `1e-12 * max(1, spectral_norm)`；超过容差的负值阻止，小容差内偏差只记录，不自动裁剪谱或增加对角项。
- 常数列保留并标记；经验波动为零并不意味真实资产无风险。Ledoit–Wolf 可能对其赋予正的模型方差，必须同时保留经验与收缩波动、披露差异。全常数输入输出退化诊断，不能标为可优化。

参考：<https://scikit-learn.org/stable/modules/generated/sklearn.covariance.LedoitWolf.html>（2026-10-17 核对）。依赖已锁定 scikit-learn 1.9.1；若作为直接运行依赖使用，在 pyproject 中显式声明同版本，不升级环境。

## S06-A 验收

1. 三资产同一训练窗口：A 月收益 `[0.01,0.03,0.02]`，B `[0.03,0.05,0.04]` 同类；C `[0,0.01,0.02]` 另一类。个体均值 `[0.02,0.04,0.01]`，类别均值 `[0.03,0.03,0.01]`，估计月均值 `[0.025,0.035,0.01]`，估计年均值 `[0.30,0.42,0.12]`。全部是人工数学样本，不是投资预测。
2. 上例样本月协方差 A／B 对角及彼此协方差为 0.0001，C 方差为 0.0001，A–C、B–C 为 0.00005；与独立手算结果逐值比较。
3. 固定小样本独立重建 Ledoit–Wolf 目标与混合式，验证输出和系数；另用固定种子 60×100 非恒定矩阵，记录样本秩不足、收缩系数、最小特征值和维度。
4. 改动或追加训练窗口外的未来收益，训练结果不变；重排资产列和类别行后按 ID 对齐结果不变。
5. 缺类别、重复 ID／月、缺月、缺值、无穷值、收益小于 -1、空输入和训练月不足均明确失败。常数／全常数及单资产输入有明确诊断。
6. 正式 S05 人工 100 项能经连接层得到估计与退化说明；排除一项后 N99 必须在数量条件处阻止。另用非恒定合格人工资料验证完整连接；真实日线仍 N0，不改标签绕过。
7. 输出诊断保留研究模式、未完成历史认证说明及方法信息；已有完整测试集回归通过，源数据不变。
