# S06-C 收益与风险界面设计

日期：2026-10-17。状态：用户已确认设计并授权实施；界面、浏览器验收和独立审查通过，完整回归713项通过。

## 目标与方案

让使用者在一次候选筛选后，看懂估计收益、产品之间的相关性，以及指定多头权重的风险与分散化；能下载对应数值与证据。复用已经验收的 S06-A/B，不重新实现公式。

推荐在“候选筛选”结果后增加“收益与风险预览”，保留原来的筛选入口、输入和下载。页面内部用页签组织结果，减少滚动。无需用户再次上传同一批资料，也无需依赖跨页面传递的旧结果。

另两种方案：独立“风险分析”页面，容易单独访问，但需要解释筛选状态如何跨页继承；一步一步的向导能减少初次使用负担，但会扩大现有导航与状态改动。本步采用结果后接入，后续有实际使用反馈再调整导航。

## 操作流程

1. 选择数据来源、共同窗口与筛选条件，点击现有“查验数据并筛选”。
2. 筛选未通过时，显示候选不足或资料缺失的原因；不开放风险计算和风险下载。
3. 筛选通过后，显示“收益与风险预览”区，并说明目标 K、合格 N 和实际预览权重覆盖数量的区别。
4. 选择“合格候选等权预览”或“上传自定义多头权重 CSV”，点击“计算收益与风险”。默认等权只用于候选池诊断，不表示已经选出 K 项产品。
5. 在“收益估计”“相关性”“风险与分散化”“方法与导出”四个页签内查验；改变原始输入或权重后撤下旧风险结果与下载，重新计算。

本步不增加成员选择、做空、优化、utility、因子回归、回撤或尾部风险。界面明确说明这些功能尚未接入，不放置看似可用的占位按钮。

## 数据与案例

保留原有 SYNTH100 数量边界演示与缺月案例，默认来源不变。新增明确命名的“SYNTH 相关性与风险演示”，提供固定种子、60 月、100 项的人工非恒定月收益，包含同向、反向和常数序列，便于复核各类状态。产品仍是人工资料，不能称为真实市场或历史表现；使用现有来源表和完整 S05 资格链路。

原来的恒定收益 SYNTH100 必须仍显示相关性不可用、零经验波动，以及相应退化说明。当前真实日线样本仍 N0；本步不补造证据、不改频率标签。

训练窗口取筛选使用的固定 60 月，不在风险区增加独立窗口，避免同一页面出现两个不一致的资格口径。

## 权重输入与错误处理

自定义 CSV 仅两列：`asset_id,weight`。weight 使用小数，0.1 表示 10%。提供基于本次全部合格 ID 的等权模板；零持仓必须明确填 0。

拒绝重复、缺失、额外 ID、空值、布尔、非数值、负值以及权重和不为 1 的资料；沿用核心的 1e-10 权重和容差。不自动归一化、不合并重复项、不自动补零。显示可操作的中文错误及缺少／多出的 ID。

同时显示“目标持仓 K”“合格候选 N”“正权重产品数”。正权重数不必等于 K，因为本步是指定权重风险诊断；界面始终标记“研究预览，尚未完成最终选品”。100 项等权不能被描述为已生成 30 项组合。

## 四个结果页签

### 收益估计

显示 HKD、窗口、60 期样本与资产数。产品表包含稳定 ID、名称、经济类别、历史算术年化均值、50%个体／50%类别均值的年化估计、经验波动、收缩模型波动、常数标记。界面百分比显示；导出保留小数原值。

用简短说明解释估计方法和年化不是 CAGR；展开项展示类别成员数、两种协方差的秩、收缩系数和数值状态。数值可优化不等于资料资格或投资适用性认证。

### 相关性

展示原始 HKD 月收益 Pearson 热图，颜色固定 -1 至 1，清楚标注负、零、正相关。默认最多显示按稳定 ID 排序的前 20 项，允许选择 2–30 项进行展示；该选择只改变图表，不改变候选 N、权重或风险。窄屏允许图表容器横向滚动，不压缩到难以辨认。

使用完整合格矩阵生成相关产品对表，支持按相关系数和绝对值排序；排除对角与重复对，显示双方 ID、名称及系数。不默认规定“相关性超过某值就剔除”。说明负相关和正相关对分散化的含义不同，绝对值高不代表都应排除。

常数产品相关项（包括自身）显示为空／不可用，不填成 0。可用产品对数量与不可用原因明确展示；可以下载完整矩阵与状态表。

### 风险与分散化

并列对照“经验协方差”和“Ledoit–Wolf 收缩协方差”，两者均使用相同估计收益和指定权重。默认以经验结果解释，模型结果单独标注。显示估计年化收益、年化波动、有效持仓数和分散化比率 DR。

有效持仓数仅解释权重集中度，不能当作独立风险来源数量。DR 接近 1 表示在该协方差与权重下分散化改善有限；不把 DR 高自动标记为安全。

提供可切换协方差口径的风险贡献条形图及完整表，包含权重、个体波动、波动贡献、风险份额。保留负贡献，说明其在当前权重下抵消部分风险；不使用无法表达负值的饼图。波动贡献用年化波动百分点展示，风险份额为占组合波动百分比，明确区分两者。

零组合波动时，DR、边际贡献和风险份额显示“不可用”，不用 0 或无穷值代替；历史常数不表示真实无风险。常数序列被收缩模型赋予正方差时提示口径差异。

### 方法与导出

展示方法、窗口、数据／筛选／计算指纹、研究模式及历史候选池未认证状态。提供收益摘要、样本／收缩年化协方差、完整相关矩阵、相关状态、两种风险贡献和风险对照 CSV，以及计算证据 JSON。JSON 不可用值写 null，禁止 NaN／Infinity。

显示筛选证据、方法与数值诊断，不把内部堆栈暴露给使用者；下载文件包含足够的信息复核同次计算。只写新验收文件，不修改已导入版本。

## 架构与状态

- `app/views/candidate_screening.py` 保持输入与筛选职责；持有本次 CandidateInput、筛选参数与输入 token，只有匹配当前 token 的通过结果才能进入预览。
- 新增 `app/views/risk_analysis.py` 管理权重模式、按钮、结果状态和中文提示；调用 `preview_candidate_risk`，由核心重新执行 S05，而非信任界面通过标记。
- 将纯格式转换、完整导出和图表数据准备拆至相邻显示辅助模块，避免把计算逻辑放入页面。
- 人工风险案例放在 universe 样本模块；不修改既有数量演示的数据含义。
- 风险状态绑定输入 token、筛选指纹、权重内容与模式；原始输入、数据版本、证据文件、K、产品范围或权重变化时，先清除旧预览与下载。计算失败也清空。只改变表格搜索、相关性展示子集、排序或风险图口径时保留结果。
- 复用已安装的 Streamlit 图表能力；不新增依赖和网络下载。沿用现有中文字体与留白，不覆盖图标字体。

## 开发拆分与验收

1. **样本与显示辅助**：固定人工案例、权重解析、空值处理、导出结构。用独立数值／错误案例验证，不复制核心公式。
2. **接入与状态**：新增风险区并接通 A/B。AppTest 验证数量不足／真实 N0 阻止、等权、上传权重、输入变化失效、展示控件不影响计算、异常无旧下载。
3. **图表与解释**：验证相关性常数空值、正负关系、同向产品 DR=1、负贡献、零波动；检查经验／模型口径没有混用。
4. **完整验收**：现有测试回归；浏览器实际操作、真实下载内容核验、宽屏与窄屏截图，检查重叠与图表可读性；源版本文件哈希不变。更新使用指南和阶段状态，独立审查后交付。
