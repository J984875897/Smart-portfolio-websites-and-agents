## 二、全程不可变的约束

1. 基准币种 HKD，优先美国和香港；上市市场、交易币种、底层经济敞口分别记录。
2. “排除个股”排除直接个股，**股票型 ETF／基金仍可进入**；按原计划处理 ADR、直接 REIT、优先股和复杂产品。
3. 正式持仓数量为整数 `20 ≤ K ≤ 100`；满足 `K/N ≤ 0.30`，N 是当前范围下去重、数据合格的候选数。
4. 边界允许等于 30%：K=20／30／50／100 时，最低 N=67／100／167／334。
5. 数量不足提示“候选产品池过小”，阻止正式生成；预览仍可用，不自动降低 K 或扩大范围。
6. 默认仅多头；开启做空表示允许做空。多空先采用固定方向方法，不宣称联合选品与方向的全局最优。
7. 所有组合统计、相关性、配置和效用使用一致的 HKD 口径；因子回归采用匹配地区的 USD 口径并明确标签。
8. 总收益、币种、频率、单位、可得时间必须可追溯；不以补零、上市前回填或重复产品扩大候选池。
9. 免费下载可选，付费接口保持关闭，CSV／XLSX 导入一直保留；缺失或未知信息显示明确状态。
10. 参数交互使用缓存，不触发行情下载；冻结的研究结果不随数据更新改变。
11. 正式组合中每个计数持仓都需满足真实权重下限；现金余量、重复项和零权重不计入 K。
12. 测试期不得参与选品和调参。只能使用当前名单时，明确标为“当前资产池的回溯分析”。

原计划中的建议参数作为开发基线：月度总收益、60 个月估计窗口、季度再平衡、默认 K=30、A=2／5／8；仅多头单项 0.5%–10%；多空净敞口 1、总敞口不超过 1.4、单项空头绝对值不超过 5%，每项绝对权重至少 0.5%。这些不应误写成老师的要求。

| `app/` | 四工作区；只调用核心，不重复写金融公式 |
| `tests/fixtures/` | 可手算样本、模拟下载响应、固定的回归样本 |
| `tests/` | 数学、业务边界、数据与时序检查 |
| `data/raw/`、`data/processed/` | 不可变原始快照和版本化统一数据 |
| `outputs/acceptance/Sxx/` | 各步查验材料及验收记录 |
| `outputs/runs/<run_id>/` | 指定数据版本和参数对应的研究输出 |
| `report/` | 与冻结运行一致的报告、图表、附录 |

接口先固定语义，再在该步细化函数签名：

- `DataBundle`：原计划 assets／returns／fx／factors 表，加快照 ID、来源和质量状态；S02 定义，S03 添加标准化 HKD 收益视图。
- `UniverseResult`：合格资产 ID、逐项排除原因、各阶段数量、K、N、比例校验、估计窗口；S05 定义。
- `EstimateResult`：按稳定资产 ID 排序的年化 mu／Sigma、日期、样本数和方法；S06-A定义。S06-B的`RiskPreview`组合此估计与原始Pearson矩阵、样本／模型指定权重风险，避免把相关性误称为收缩模型相关性。
- `SelectionResult`：K 个互异成员、手动指定项、方向、入选／替代理由、分组；S07 定义。
- `AllocationResult`：资产 ID 对应权重、输入版本、A、utility、约束残差、求解状态；S08 定义，S09 扩展多空成本字段。
- `BacktestResult`：决策时间、持仓生效时间、逐期头寸／交易／成本／净值、使用快照；S11 定义。
- 所有失败结果有明确状态和原因，不能用旧权重冒充新参数的成功结果。数值矩阵必须核对资产顺序，禁止只按数组位置拼接。

每步固定保存 `outputs/acceptance/Sxx/README.md`、`checks.txt` 和具体结果文件。README 包含输入版本、实际执行命令、预期／实际结果、异常案例、未解决问题，以及“未开始／开发中／待查验／通过／未通过”。此状态须由证据支持；先前完成安装不能直接把 S00 标为通过。

进入开发后，核心规则采用小步循环：准备可独立计算的预期结果 → 编写并运行失败检查 → 最小实现 → 检查通过 → 生成查验产物 → 更新记录。每轮提交范围限于当前步骤及必要修复。使用 Git 时不提交密钥、`.venv` 或无授权再分发的数据。

**通过标准：** 无噪声满秩样本的系数误差不超过 1e-8；有噪声样本用固定种子并核对参考统计结果，不强求估计恰好等于真值。香港样本完成 USD 换算；债券／黄金不被强制套用股票 FF5；alpha 显示币种和期间，不直接加进未来收益。
