# 日线汇率导入格式

在「日线港币查验」中，USD 产品可选择导入 CSV 或 XLSX；XLSX 需选择工作表。原文件只用于当次预览，不会自动保存进产品数据。

每行是一个实际观察日的美元汇率，列名固定：

```csv
date,currency,hkd_per_unit,source_name
2024-12-31,USD,7.8,SYNTH_EXAMPLE
2025-01-31,USD,7.9,SYNTH_EXAMPLE
```

这两行是人工示例，不是真实历史报价。`date` 必须为 `YYYY-MM-DD`；`currency` 固定 USD；`hkd_per_unit` 是一美元兑多少港币，必须为有限正数；`source_name` 写明实际来源。不要把港币兑美元的倒数直接填入。软件不自动识别或反转报价。

软件为每个自然月末寻找同一月份内日期最后的一条记录，并显示真实日期和距月末的日历天数。默认上限为7天（可设0–7，等于允许），属于本项目研究政策。最新记录无效或重复，即使重复值相同也阻止该端点；不会回退到更早的有效报价。缺少整月不会借用上月或下月数据。日历完整性未在此认证，较早行的问题会保留在逐行诊断中。

预览2025年1月收益，需要2024年12月与2025年1月两个端点，以及两个完整价格月份。月末为周末时可以选用本月较早且满足年龄上限的实际报价。核对单位后勾选确认，才允许生成美元产品的港币收益。

原始文件哈希、工作表、输入行号与选出的端点随结果保留。观察日期不代表当时可获得的时间；当前预览不具备历史可得认证。港币产品按1:1处理，不需要此文件。
