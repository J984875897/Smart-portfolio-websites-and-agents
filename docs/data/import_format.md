# S02 导入格式与质量检查

本步支持本地 UTF-8／UTF-8 BOM CSV 和 XLSX。采用长表：一行表示一个产品、一个日期、一个数值。第一行须为表头；Excel 可以选择工作表。股票代码建议存为文本，例如 `0700`，避免 Excel 已经丢失前导零。

## 字段与默认值

| 字段 | 含义 | 选择方式 |
| --- | --- | --- |
| `asset_id` | 已有的稳定产品标识 | 可映射；没有时按明确的上市身份生成 |
| `ticker` | 产品代码 | 列映射或单一产品默认值 |
| `name` | 名称 | 可选；不用于相似名称合并 |
| `exchange` | 明确的交易所／市场 | 列映射或默认值；不根据币种猜交易所 |
| `currency` | **该数值原本的币种** | 列映射或默认值，如 USD／HKD |
| `share_class` | 份额／柜台标识 | 可选；不同份额不要沿用同一个资产 ID |
| `tool_type` | 工具类型 | 列映射或明确默认值，逐产品修正可留记录 |
| `asset_class` | 经济资产类别 | 列映射或明确默认值，与工具类型分开 |
| `date` | 数值对应日期 | 列映射，并选择文件日期格式 |
| `value` | 价格或已提供的单期收益 | 列映射，并明确口径与单位 |
| `frequency` | 日／周／月／季／年 | 列映射或默认值 |

行内值优先于默认值；默认值只补空白。无效的行内分类会报告错误，不能自动回退。缺少必要分类不会被默认当作个股。当前工具类型包括 `stock`、`ETF`、`fund`、`mutual_fund`、`gold_trust`、`bond`、`REIT`、`cash`、`commodity`、`index`、`derivative`；资产类别包括 `equity`、`bond`、`fixed_income`、`cash`、`commodity`、`real_estate`、`mixed`、`alternative`。类型可记录不代表已获准进入正式投资范围，后续 S05 再筛选。

## 数值口径

- `price`：来源价格；应先核对供应商是否已作拆股调整。
- `adjusted_price`：来源调整价格代理；本步只导入，不计算总收益或额外加分红。
- `total_return`：文件已经提供的含分红单期总收益。
- `price_return`：文件已经提供的价格收益，不冒充总收益。

选择“百分数”时数值 `2` 表示 2%，标准化为 `0.02`；选择“小数”时 `0.02` 表示 2%。收益栏填数字，不带 `%` 符号；价格不会除以 100。Excel 原生日期的午夜日期值可按 ISO 日期读取，CSV 的文本日期严格遵守所选格式，不自动猜日／月顺序。

## 查验与保存

先查看原始表，映射字段，再运行质量检查。每个结果保留文件名、Excel 工作表、原始行号和原文件 SHA-256。CSV 来源行号对应记录开始的文件行，包括前面的空行；多行引号字段保留其开始行。重复观察不新增产品或数值，来源记录仍保存。

非法日期、缺必要分类／数值、非有限数值、非正价格、收益低于 -100%、身份或数值冲突，会阻止相应行。合法但绝对值达到 50% 的单期收益属于本步的核对提示，保留数值，明确确认后才可导入；-100% 也可合法，但需核对。此阈值只用于导入查验。缺失值保留缺失，不用零替代。

同一上市身份的不同来源可使用已有来源别名或明确人工映射。映射只能连接相同交易所、币种和份额的产品，不把 HKD／CNH 柜台或不同份额强行合并。产品分类修正保留原值、新值、来源行和修改时间。冲突新行不会覆盖已有数值。

保存生成新 DataBundle 版本，包含产品、原币观察值、导入来源、质量报告、别名、分类修改记录及原始文件。重新载入会核验表文件及原文件校验值，拒绝覆盖已有版本。来源文件本身仍是判断价格和收益含义的依据；哈希用于完整性核对，不能证明资料真实性。

本步尚未完成交易日历、月度估值、60 个月资格检查及 HKD 换算；数据导入数量不是合格候选数 N。完整下载缓存和异常更新恢复在 S04。
