# Smart Portfolio · 投资组合研究工作台

**简体中文** | [English](README_EN.md)

**Portfolio Research Workbench · HKD Base · US & Hong Kong**

一个正在开发的可复用投资研究系统：从数据导入、质量核对和候选筛选出发，逐步构建可解释、可复算的投资组合研究流程。

这是一个由我独立设计、开发并持续迭代的个人项目。目标是把投资理论转化为可以实际操作的研究工具：检查数据是否可靠，解释产品之间的风险联系，并逐步探索不同投资者的风险偏好如何影响组合配置。

**当前状态：开发中，已完成 S07-A 成员选择核心。** 工作台已提供数据研究、候选筛选和收益与风险预览；成员选择核心尚未接入界面。Utility、权重优化、做空、因子回归和完整回测按后续阶段实现。


[快速开始](#快速开始) · [当前功能](#当前功能) · [使用指南](docs/USER_GUIDE.md)

## 操作流程

准备数据 → 核对资格 → 筛选候选 → 收益与风险。后续模块按开发路线逐步接入。

## 项目思路

- **统一计价。** 以港币为研究基准，优先覆盖美国和香港产品，显式核对美元资产的汇率影响。
- **先查数据，再做研究。** 保留原始来源、数据版本、质量报告和决策时点证据；缺失或不合格的数据会说明原因并阻止后续计算。
- **把候选数量与风险分散分别核对。** 满足持仓数量并不等于风险充分分散，需要继续检查相关性、权重集中和风险贡献。
- **让结果可以解释。** 筛选与成员选择输出逐项原因，研究结果可导出为 CSV／JSON，并保存阶段验收材料。

## 当前功能

| 模块 | 已实现的内容 | 使用入口 |
| --- | --- | --- |
| 数据导入与版本 | CSV／XLSX、工作表与字段映射、产品分类、逐行质量检查、去重、本地保存与重读 | 01 准备数据 |
| 收益与资格核对 | 原币与 HKD 收益、日线月度检查、汇率端点配对、固定 60 月共同窗口、本地版本取得时间核对 | 02 核对资格及相关工具 |
| 数据下载与缓存 | Yahoo 小样本行情／汇率、French 因子下载、下载计划、原始快照、离线重读及失败诊断 | 数据工具与证据 |
| 候选筛选 | 市场、产品分类、是否纳入个股、目标数量 K、合格候选 N、数量漏斗与逐项排除原因 | 03 筛选候选 |
| 收益与风险 | 历史／类别收缩收益估计、样本／Ledoit–Wolf 协方差、Pearson 相关性、等权或指定多头权重的风险预览 | 04 收益与风险 |
| 分散化诊断 | 相关热图、高相关产品对、波动、风险贡献、有效持仓数和 Diversification Ratio | 收益与风险页签 |
| 成员选择核心 | 确定性相关性分组、手动纳入／不入选、类别最低数量、费用／流动性排序、逐项入选理由与候补对照 | 计算核心，尚无页面按钮 |

目标持仓数 **K 为 20–100 的整数**，要求 **K / N ≤ 30%**，其中 N 为当前筛选后数据合格的候选数。例如，选择 30 项至少需要 100 项合格候选；不足时提示“候选产品池过小”。

关闭“个股”只排除直接持有的个股，**股票型 ETF／基金仍可进入候选范围**。目前风险页面只支持多头研究预览；做空开关属于后续计划。

## 快速开始

### 1. 安装环境

当前已验证环境为 **macOS arm64、Python 3.14.6**，项目要求 Python `>=3.14,<3.15`。其他平台尚未完成验证。获取源码后，在项目根目录运行以下命令（macOS／Linux shell）：

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock.txt
python -m pip install --no-deps --no-build-isolation .
python -m pip check
```

首次安装依赖需要联网。已安装本项目环境时，可直接从激活虚拟环境开始。

### 2. 启动工作台

```bash
python -m streamlit run app/main.py --server.address 127.0.0.1 --server.port 8502 --server.headless true --browser.gatherUsageStats false
```

终端保持运行，在浏览器打开 **http://127.0.0.1:8502**。这是本地应用地址，不是线上演示站点。

### 3. 用人工数据体验

1. 在“研究总览”点击 **试用人工演示**，进入“03 筛选候选”。
2. 保留默认人工相关性案例和 K=30，点击 **查验数据并筛选**，查看 N=100、K/N=30% 及逐项原因。
3. 点击 **前往收益与风险**，保留“合格候选等权预览”，再点击 **计算收益与风险**。
4. 查看收益估计、相关性、风险与分散化，以及方法与导出四个页签。

此处展示的是 **100 项候选的等权风险预览**，并未在页面中选出 30 项持仓。S07-A 的30项成员草稿可通过计算核心及人工测试复算。

人工演示无需联网或准备自己的文件。换用自己的资料时，从“01 准备数据”开始；完整操作和常见阻止状态见[使用指南](docs/USER_GUIDE.md)。

当前工作台界面以中文为主；仓库首页提供中英文说明，尚未实现界面语言切换。

验证可通过下列命令在本地运行。完整回归中的真实来源案例依赖开发者本地保存的下载和验收材料；这些材料不随公开仓库分发。

```bash
python -m pip install --no-deps --no-build-isolation --force-reinstall .
```

## 数据与当前边界

本地文件导入和人工演示可独立使用；联网下载由用户明确触发，当前未接入付费接口。Yahoo 免费路径为非官方接口，French 提供因子文件；可用性、覆盖范围和口径仍需核对，不能保证免费获取全部投资产品数据。接口与字段说明见[来源矩阵](docs/data/source_matrix.md)。

现有验收中，HKMA 官方汇率在线路径仍失败，部分 Yahoo 汇率版本不完整；真实日线样本尚未形成通过全部资格检查的候选池，相关案例 N=0。今天下载到历史价格，也不能单凭下载记录证明过去已经取得该版本；历史可投资名单和源站发布时间认证仍待完善。

当前产物是研究预览和成员草稿，尚无经过完整优化与回测的正式组合。持仓数量、有效持仓数、相关分组和风险贡献各自反映不同信息，单项通过不能作为“风险已充分分散”的结论。
