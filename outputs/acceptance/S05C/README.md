# S05-C 候选筛选页面

本步把 A 的原始输入查验与 B 的规则接入工作台。左侧新增「候选筛选」；可以调整范围、检查候选数和原因、下载完整结果。尚不选择组合成员或分配权重。

## 先用三分钟体验

1. 打开[本地工作台](http://127.0.0.1:8501)，左侧选择「候选筛选」。
2. 保留「SYNTH 100项边界演示」、结束月2025-01、默认含时区决策时间和K30，点击「查验数据并筛选」。应显示N100、30.000%、最低100、缺口0、「数量条件通过；尚未生成组合」。
3. 在「手动排除」搜索并选中 `SYNTH_SCREEN_099`。旧结果和旧下载立即撤下；再点击查验，得到N99、30.303%、缺口1和「候选产品池过小」。
4. 在产品表搜索、改变展示状态或翻页，N不变。下载的CSV仍含完整100项，手动排除项会注明原因；矩阵只含合格列。

人工100项是明确标记的规则案例，收益刻意固定，不能用来证明分散化、风险合格或真实投资表现。股票ETF在默认剔除个股模式下仍可通过。

## 如何使用自己的数据

先在「数据导入」保存或打开版本，再回本页选择「当前已打开导入版本」。来源旁显示当前版本名和观察行数。本页不会改写原始版本，也不自动下载或扩充产品池。

上传月末FX、逐月时间和结构资料CSV／XLSX，可选Excel工作表；模板在「证据格式与空白模板」。HKD原币不需要FX，外币需要精确起止月末汇率。结构资料必须按asset_id绑定并保留来源；ETF不自动视为普通非杠杆产品。跨上市关系可另行上传，明确组别及代表，不自动按名称或高相关收益合并。

当前研究要求同一60月HKD收益与声明时间条件完整。已有真实3项、8,305条日线尚缺共同月度准备及相关证据，因此页面正确返回N0，并保留 `monthly_preparation_required` 等原因。不要将daily标签改为monthly绕过准备。

选择市场、工具、经济类别，切换是否允许直接个股，设置K20–100整数。默认关闭个股；股票ETF／基金仍可选。修改这些范围、时间、证据文件或源数据后，旧结果及导出撤下，点击后重算；切换来源或版本还会清空旧上传及复权确认，要求对新输入重新核实。

漏斗依次为资料行数→身份合格去重→范围内→数据合格N。排除说明放在表格前三列，英文规则代码保留在表与导出中。费率和流动性未提供；预期收益、波动、相关性及alpha／beta待后续步骤估计。数量通过不说明组合已形成或风险已合格。
