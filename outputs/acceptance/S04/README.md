## 尚未解决与下阶段边界

1. HKMA 官方 FX 在线仍失败；当前没有自动历史 HIBOR 下载。
2. 新 USD 两月完整链路仍受 FX partial 阻止，不能报告“全部来源已更新成功”。保留导入与其他来源选择，不自动替换来源身份。
3. C3 依赖本地时钟、清单及散列，不认证源站历史发布时间或历史候选名单；日线 C2/C3 尚未接入 S03 共同窗口。
4. 当前只支持七个 Yahoo 识别样本，没有海量候选池、正式 N、持仓生成、相关矩阵或 utility。

下一轮先设计 S05 的候选资格与输入边界，区分“当前资产池回溯研究”和“历史时点认证”。S05 合成边界验证依赖已验收 S03，可按原计划独立设计；真实候选验收仍需 S04 相应数据合格，不绕过失败来源，也不直接进入组合优化。
