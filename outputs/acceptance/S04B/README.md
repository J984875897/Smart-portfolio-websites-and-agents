## 用户操作

在 [本地工作台](http://127.0.0.1:8501) 选择「因子与官方汇率」。

1. 默认五个数据集，日期为 2025 全年；点击「生成下载计划」，核对来源、币种、频率及最大请求数。此时不联网；可取消。
2. 要联网更新时明确点击「开始下载」。每个 French ZIP 全量下载后过滤月份；HKMA 每页至多 1000 行，短页提前结束，有最大页数保护。只支持开始前取消同步下载。
3. 离线查验可直接选择上述已有版本，点击「校验并打开缓存」。应显示四项各 12 行成功、HKMA 不可用；失败项不进入成功数据选择。
4. 选择美国 FF3／FF5，对照 2025-01 的 SMB；可导出派生表、原始 ZIP／CSV、清单及更新日志。不会送入产品导入或自动写入 DataBundle。
5. 改日期／数据集／超时后原计划失效；已打开缓存保持自己的原请求期间和版本，不冒充新参数结果。新下载不会自动替换已打开缓存。

## 复现命令

项目目录内执行，仅 `--online` 联网。正式快照和下载日志不能覆盖旧版本；相同请求再次执行产生新版本。

```bash
.venv/bin/python scripts/verify_reference_downloads.py --replay 20261016T122003876246Z-5ad84dbff22343d99fe0fe73ee5d800f
.venv/bin/python -m pytest -q
# 按需联网，当前网络下 HKMA 可能继续失败：
.venv/bin/python scripts/verify_reference_downloads.py --online
```

该核验脚本在任一来源未成功时退出码为 1；这不等于缓存完整性失败。请同时检查 `snapshot_integrity_verified=true` 与 `all_requested_sources_success=false` 以及逐项原因。本次在线、离线均为这个明确的部分来源成功状态。
