# S03-A 月度收益与港币换算验收

日期：2026-10-13。本子步骤完成开发与离线数值检查；S03 整体尚未验收。S03-B 时间对齐／连续 60 月共同窗口及 S03-C 港币无风险代理未开始。这里没有真实投资组合结果。

## 在界面查验

打开 http://127.0.0.1:8501，左侧选择「港币收益查验」。

1. 选择「人工测试案例」。这些是专门构造的测试数字，不是真实市场记录，也不会覆盖导入页的已保存版本。
2. 在「汇率输入」明确选择「完整人工汇率案例」，点击「计算港币收益对照」。美元 ETF 行的原币收益应为 1.000000%，港币收益为 2.294872%；港币 ETF 行保持 1.000000%。
3. 「人工已调整价格示例」默认被阻止。逐资产确认框勾选 `SYNTH_ADJ` 后重新计算：2025-01-31 行应为 2.294872%；2024-12-31 首期仍因缺少前月价格被阻止。
4. 改选「缺少期末汇率案例」：旧结果立即失效，重新计算后美元行港币收益为空／None／NaN，处理状态为阻止；港币行仍为 1%。缺失不等于零。
5. 展开「完整对照、来源证据及 CSV 下载」，可查看起止汇率、原币收益、来源文件、行号、SHA-256 和逐行处理原因。完整表及 CSV 的收益以小数表示，0.01 代表 1%。

自己的数据可从「当前已保存数据」进入，FX 支持 CSV／XLSX 和工作表选择。必需字段为 `date,currency,hkd_per_unit,source_name`；汇率方向为每一单位外币对应的港币数。本步仅处理明确标为 monthly 的自然月末观察，FX 必须精确匹配两端日期；日线和其他日期留待 S03-B，不能直接把日期改成月末来绕过校验。

## 独立复算结果

公式：`HKD return = (1 + local return) × FX_end / FX_start − 1`。

| 人工案例 | 原币收益 | 汇率起止 | 港币收益 |
| --- | --- | --- | --- |
| 美元总收益 | 1% | 7.8 → 7.9 | 2.294871794872% |
| 港币总收益 | 1% | 无需 FX | 1% |
| 美元零收益 | 0% | 7.8 → 7.9 | 1.282051282051% |
| 美元全损 | −100% | 7.8 → 7.9 | −100% |
| 已确认调整价格 100 → 101 | 1% | 7.8 → 7.9 | 2.294871794872% |

人工全损行在测试导入中显式接受核对提示。复算有 5 个资产、6 条观察、5 条有效 HKD 收益和 1 条首期阻止记录。原始观察保持不变。

## 本步边界

普通价格与价格收益不能冒充总收益；调整价格必须逐资产确认，不再额外加分红。重复冲突、缺月、无效值和缺 FX 输出原因，不补零、前填或使用固定联系汇率。

人工数据只验证计算与失败处理。尚未证明真实行情的跨市场可得时点、交易日历或历史修订可得性，也未建立连续 60 月窗口、正式候选 N、港币无风险代理、Sharpe、utility 或回测。下一子步骤为 S03-B。
