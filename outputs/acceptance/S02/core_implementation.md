## Public API (portfolio.data)

`ImportConfig(mapping: dict[str,str], source_name: str, defaults: dict[str,str]={}, value_kind: str='price', return_unit: str='decimal', date_format: str='%Y-%m-%d', sheet_name: str|int=0, classification_overrides: dict[str,dict[str,str]]={}, alias_mappings: dict[tuple[str,str,str,str,str],str]={})` frozen dataclass. Dictionaries are caller supplied mutable values; do not mutate after preview. Mapping canonical->source field is explicit, unmapped fields stay blank. Canonical fields asset_id, ticker, name, date, value, tool_type, asset_class, exchange, currency, share_class, frequency. market mapping/default accepted as exchange synonym. Defaults fill only blanks. Invalid explicit row enums never fallback. No implicit stock/class defaults. Override keyed asset_id contains tool_type and/or asset_class; conflicts require explicit override. External manual alias tuple order source_name, exchange, ticker, share_class, currency -> existing canonical asset_id. Existing alias must target actual prior asset; ticker/source changes allowed, currency/exchange/share class changes always blocked.

`read_file(data: bytes|str|Path, *, filename: str|None=None, sheet_name: str|int=0) -> pd.DataFrame`. Path is local only; bytes need filename. CSV UTF8/BOM strings and XLSX openpyxl strings preserve 0700 and NA/NULL; XLSX numeric cells cannot restore display-format leading zeros. XLSX selected actual sheet name retained attrs. attrs source_file, raw_bytes, source_sheet (XLSX). Unsupported extensions raise ValueError.

`preview_import(data: pd.DataFrame|bytes|str|Path, config: ImportConfig, existing: DataBundle|None=None, *, filename: str|None=None) -> ImportPreview`. Preview has rows DataFrame, issues DataFrame, config, source_hash, source_file, raw_bytes; counts property status->count. DataFrame fallback filename dataframe.csv; no prior bundle mutation. Rows carry canonical asset metadata, normalized date/value, source_file, source_sheet (empty CSV), original source_row (header row1, data row2), source_hash, source_name, value_kind, status. Status valid/review/blocked/duplicate. Issues columns source_file,source_sheet,source_row,source_hash,asset_id,code,severity,message. Core assumes rectangular files with first row header (no arbitrary header offsets).

`commit_import(preview: ImportPreview, existing: DataBundle|None=None, *, allow_review: bool=False) -> DataBundle`. Pass same existing bundle used for preview. Creates independent copy, accepts valid, explicitly acknowledged review, no blocked observations. Pending review provenance is review_pending. Duplicate observations add provenance but no observation/product inflation; explicit duplicate classification correction is applied and logged. Quality report retains all incoming findings including blocked/review. Each incoming row has provenance. Aliases exact and persisted. No fuzzy matching.

`DataBundle()` exposes DataFrames assets, observations, provenance, issues, aliases, classification_history, returns, fx, factors; configs list and raw_sources dict SHA->bytes. Returns only supplied total_return/price_return observation view; no normalization/conversion. fx/factors empty S03 placeholders. `save(path: str|Path)` creates new folder only (FileExistsError existing), version1 CSV tables and JSON manifest with schemas/configs/SHA hashes plus raw binary sources. `DataBundle.load(path)` validates version, all required table names, exact schema columns, each file SHA, safe basename manifest paths, raw SHA, numeric value/source_row types; IDs stay strings.
