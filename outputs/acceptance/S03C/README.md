## 方法的实际边界

采用月初已经可得的 HKAB 1个月 HIBOR 年化报价，按完整自然月的实际日数单利计息。它是**含银行信用风险的现金收益近似代理**，不是零风险资产、个人可取得的存款报价、实际实现的收益或真实存款合同期限认证。

月初／期末锚点为相应自然月末香港16:00，七天陈旧阈值是明确的研究选择。可得时间由导入者声明；软件核对逻辑，不独立认证历史报价版本、真实最新 fixing、节假日或供应商发布时间。文件 hash 及物理行用于定位计算输入，不认证声明内容真实。

本步无联网行情下载。真实日线自动月度聚合、交易日历认证与历史发布时间自动接入仍未交付；S03 人工月度查验不等于真实资产池已可回测。S04 免费下载及缓存留待下一步。
