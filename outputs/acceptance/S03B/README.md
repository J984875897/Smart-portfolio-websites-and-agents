# S03-B：月度时间对齐与共同窗口

状态：S03-B 开发验收通过（2026-10-16）。核心、页面、独立复查、完整回归及实际浏览器验证已完成。S03 整体仍待 S03-C。

## 查验目标

所有产品按同一个结束月份往前取连续 60 个月。每月必须有有效 HKD 收益、两端真实估值时间，以及所有输入及版本的最晚可得时间。缺月不补零、不拿窗口外的老数据替补；实际 0% 收益可用。

使用 [设计](../../../docs/superpowers/specs/2026-10-13-s03b-alignment-design.md)、[实施计划](../../../docs/superpowers/plans/2026-10-13-s03b-alignment-implementation.md) 和 [时间证据格式](../../../docs/data/alignment_format.md)。

## 人工案例的独立预期

全部为人工验证输入，通过 S03-A 实际换算函数生成 HKD 对照；不是投资产品或真实历史。每月原币收益设为 1%，人工外币汇率为固定测试值。固定汇率仅用于本案例，系统实际计算仍读取逐期 FX 序列。

结束月：2025-01；固定窗口：2020-02 至 2025-01。

| 人工产品 | 2025-01-31 17:00 香港时间 | 2025-02-01 06:00 香港时间 |
| --- | --- | --- |
| 港币历史完整 HKD_COMPLETE | 60/60，通过 | 60/60，通过 |
| 美元历史完整 USD_COMPLETE | 59/60，末期资料尚不可得 | 60/60，通过 |
| 中间缺月 MISSING_MIDDLE | 59/60，缺 2022-06 | 59/60，仍排除 |
| 仅 59 月 SHORT_HISTORY | 59/60，缺 2020-02 | 59/60，仍排除 |
| 缺期末 FX MISSING_END_FX | 59/60，缺 2025-01 期末汇率 | 59/60，仍排除 |

较早决策矩阵应为 60×1；较晚为 60×2。通过数只是本步的完整窗口产品数，不是 S05 的正式候选数 N。

## 本地复算

```bash
PYTHONPATH=src .venv/bin/python scripts/verify_alignment.py
.venv/bin/python -m pytest tests/test_alignment.py tests/test_alignment_view.py -q
```

脚本独立断言所有产品的有效月份数、矩阵边界、通过 ID、每月 1% HKD 收益及缺 FX 原因，并输出至 [synthetic](synthetic/)：两份报告、逐月记录、矩阵、原始对照、时间输入和 [summary.json](synthetic/summary.json)。日期索引为月末标签；收益 CSV 为小数单位。

## 页面手工查验（2026-10-16）

打开 [本地研究数据工作台](http://127.0.0.1:8501)，选择左侧「共同窗口查验」→「人工测试案例」。时间证据输入应自动显示「人工时间证据」。保留结束月份 `2025-01` 和默认决策 `2025-01-31T17:00:00+08:00`，点击「查验共同窗口」：摘要为「通过 1 / 5 资产」，港币完整案例 60 月，其余 59 月。

把决策改成 `2025-02-01T06:00:00+08:00` 并按 Tab 或点击其他位置提交输入，旧摘要及结果下载消失；重新查验应为「通过 2 / 5 资产」，美元完整案例也到 60 月。展开「完整证据、固定矩阵与下载」可查看两份矩阵及导出报告、覆盖证据、矩阵 CSV。真实输入选择「上一页当前港币对照」，并上传完整时间表；无有效上游对照时按钮禁用且提供操作指引。
