状态：**S04-A 开发验收通过，供小组查验。** S04 总体尚未验收。

## 在界面核对

打开 [本地工作台](http://127.0.0.1:8501)，左侧选择「下载与缓存」。

1. 不联网查看：在「下载记录（按时间倒序）」选择 SPY 恢复版本（编号以 `20261016T032452` 开始），点「校验并打开缓存」。应显示 SPY、USD、20 行，2025-01-02 至 2025-01-31。可导出日线、导入 CSV、快照清单及更新日志。
2. 导入交接：点「送入数据导入核对」，应回到「数据导入」，来源文件含原版本编号，日频、USD、ETF／权益及复权价格口径已经带入。点「质量检查」，20 行均可接受，0 行待核对／阻止／重复；没有自动保存。
3. 部分成功历史：打开以 `20261016T032413` 开始的记录，SPY 不可用，2800.HK 成功 19 行、HKD=X 成功 22 行；这是初次真实下载的结果，不能改称整批成功。成功项可以分别查看。HKD=X 方向是 HKD per USD，只能导出日线，不作为现金产品导入。
4. 准备与取消：默认选择 SPY／2800.HK，2025-01-01（含）至 2025-02-01（不含），点「生成下载计划」，核对产品身份、币种、请求数 2 和超时，再点「取消下载计划」。不会产生新快照，也不会联网。改变日期或所选项后旧计划撤销。
5. 明确更新：重新生成计划，点「开始下载」才联网。各项独立显示状态；更新结果与已打开缓存分开。取消只限开始前，页面明确提示同步执行不能中断在途请求。失败时可继续使用已打开旧缓存。

有 `partial` 日线时，页面提供「部分可用日线 · 诊断查看与导出」，原样保留 NaN；它独立于成功缓存选择，不能送入产品导入。全 partial 记录可诊断但保留先前成功缓存。此分支用离线固定响应验证，与真实来源结果分开，不把模拟数据写入真实缓存。

## 边界

本轮七个代码为来源识别样本，不是全市场覆盖或正式候选池。成功只代表字段检查，不保证完整交易日历、历史 available_at、月度 HKD 收益或可投资性。Adj Close 为供应商总收益代理，不重复加分红；日线自动月度聚合尚未接入。下载时间是本次请求时间，不能伪装成历史可得时间。

免费入口没有服务保证和无限请求承诺；只用于本地课程研究，付费及需要 key 的来源继续关闭，CSV／XLSX 导入保留。French、HKMA（此前 TLS 失败未声称解决）在 S04-B 继续做。部分返回数据只能诊断，不作为可用产品缓存或计入候选数量。当前没有生成投资组合。
