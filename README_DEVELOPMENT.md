## 查验历史观测时间资格

打开[本地工作台](http://127.0.0.1:8502)，左侧选择「历史资格与来源」：

1. 选择「SYNTH 时间案例」。默认决策时间 `2025-02-02T00:00:00+00:00`，应显示 **1** 个本地版本时间通过月。这是模拟价格和汇率的取得时刻。
2. 将决策时间改为 `2025-02-01T23:59:59.999999Z` 并按 Enter，通过月数变为 **0**，原因是本地取得时间晚于决策时点。改回原时间即可恢复。
3. 可填写人工声明时间作对照；声明不会使证据不足的版本获得资格。下方可下载 CSV、JSON，或展开完整散列与记录。

查验自己的数据：先在「日线港币查验」计算结果，再返回本页选择「上一页日线港币结果」。页面会重新验证本地价格／汇率快照。新下载保存 `completed_utc`；旧快照没有此字段会提示“时间证据不足”，不会回填。真实数据的决策时间需按实际研究时点输入；今天下载的历史价格不能凭今天的下载记录通过过去的决策时点。USD 需价格和 FX 两份证据，HKD 只需价格。人工价格或上传汇率缺少可核验快照时会说明缺失。

通过只表示该本地版本在给定时点前已取得，仍不能证明历史资产池完整，也不自动送入共同窗口或候选数 N。取得时间依赖本地时钟和清单记录，不是独立时间戳认证。

## 查验日线港币月收益

打开[本地工作台](http://127.0.0.1:8502)，在侧栏「快速跳转至任意工具」选择「日线港币查验」：

1. 价格保留「人工案例／完整报价」、SPY，起止月份均为 `2025-01`，勾选复权价格确认。
2. 汇率保留「人工案例／完整汇率」，勾选「每美元兑港币」确认，最大年龄保留7日。
3. 点击「查验并计算港币收益」。应显示1个可预览月，原币10%、汇率约1.2821%、交叉项约0.1282%、港币约 **11.4103%**。

把汇率案例改成「缺期末月」「过旧」或「重复末日」再查验，港币收益会被阻止并说明原因。改动任何输入后旧结果和结果下载立即撤下。换成2800.HK人工完整报价，原币与港币收益均为10%，无需美元汇率。

可显式选择已有价格缓存、HKMA官方或Yahoo非官方汇率缓存，也可上传CSV/XLSX并选择工作表；格式见[日线汇率导入](docs/data/daily_fx_format.md)。本页不联网；缺数据时请到下载页面单独下载。预览一月需要完整前月价格与两个汇率月份，建议下载 `2024-12-01` 至 `2025-02-01`（结束日不含）。人工与真实数据混用只作演示。

默认FX距离自然月末最多7个日历日（可调0–7，等于允许），这是研究假设。结果保留实际价格／汇率日期、年龄、原文件哈希与来源；逐行诊断及CSV/JSON在折叠证据中。此处仍是当前版本的异步估值预览，尚不具备历史可得资格，也不保存至共同窗口或形成候选N。[本步验收材料](outputs/acceptance/S04C2/README.md)记录真实离线复算、在线限制与检查状态。

## 重建环境

当前基线为 **Python 3.14.6、macOS arm64**；`pyproject.toml` 暂将 Python 范围限定到 3.14。已验证本机从空虚拟环境安装锁定依赖并重复运行；其他 Python 版本、操作系统和架构需要另外验证。

在有 Python 3.14 的机器上，从项目目录执行：

```bash
python3.14 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python -m pip install --no-deps --no-build-isolation .
.venv/bin/python -m pip check
.venv/bin/python -m pytest tests/test_smoke.py -q
.venv/bin/python -m portfolio.demo
```

首次安装依赖需要联网；样例和测试使用本地固定输入，可以离线运行。`requirements.lock.txt` 当前固定 104 个依赖及测试／打包工具的版本，包含 vectorbt、yfinance、Streamlit、openpyxl；S02 新增 22 个依赖，原 77 个版本保持不变，当前没有锁定下载文件哈希。

采用标准包安装。修改 `src/` 后，用下面命令更新环境中的本地包，再运行检查：

```bash
.venv/bin/python -m pip install --no-deps --no-build-isolation --force-reinstall .
.venv/bin/python -m pytest tests/test_smoke.py -q
```

测试会直接检查已安装的命令行入口，避免仅在源码目录可运行。当前机器的开发安装路径文件曾受到 macOS 隐藏标记影响，处理过程保存在验收目录。
